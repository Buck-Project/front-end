# React Authentication App

یک اپلیکیشن احراز هویت با React و Tailwind CSS

## نصب و راه‌اندازی

### نصب پکیج‌ها
```bash
npm install
```

### اجرای پروژه
```bash
npm start
```

پروژه روی [http://localhost:3000](http://localhost:3000) اجرا می‌شود.

### ساخت پروژه
```bash
npm run build
```
